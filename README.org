* 戦国風雲録

信長の野望・武将風雲録風の戦国シミュレーションゲームを、Emacs Lispで遊べるパッケージです。
Emacs 27.1以降に対応し、ゲーム本体に外部パッケージは必要ありません。

本作は、元ネタのVIM版 [[https://github.com/miraihack/VimnaganoYabo][miraihack/VimnaganoYabo]] にインスパイアされたEmacs版です。

*全41ヶ国・32大名家・256武将*。1560年（桶狭間の年）の日本を舞台に、南部から島津まで好きな大名家で天下統一を目指します。

* 必要環境

- Emacs 27.1以降
- 標準添付ライブラリのみ（~cl-lib~, ~seq~, ~subr-x~, ~json~）
- 推奨ウィンドウサイズ: *115桁 × 40行以上*（戦略マップは110表示桁）

GUI EmacsとターミナルEmacsのどちらでも遊べます。日本語を含む盤面は ~string-width~ を基準に整列します。

* インストール

リポジトリを任意の場所へ置き、Emacsの ~load-path~ に追加します。

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/EmacsanaganoYabo")
(require 'sengoku)
#+end_src

Emacs 30以降では、組み込みの ~use-package~ と ~:vc~ を使ってGitHubから直接インストールできます。

#+begin_src emacs-lisp
(use-package sengoku
  :vc (:url "https://github.com/askdkc/EmacsnaganoYabo"
       :rev :newest)
  :commands (sengoku
             sengoku-load
             sengoku-self-test
             sengoku-siege-test))
#+end_src

この設定をinitファイルへ追加すると、未導入の場合はリポジトリからパッケージを取得し、各コマンドを自動ロード対象として登録します。

Emacs 29以降では、ローカルリポジトリを ~package-vc-install~ で登録することもできます。

#+begin_src emacs-lisp
(package-vc-install
 '(sengoku :url "file:///path/to/EmacsanaganoYabo"))
#+end_src

設定ファイルを読み込まない、まっさらなEmacsで直接起動する場合は次のコマンドを使います。

#+begin_src sh
/Applications/Emacs.app/Contents/MacOS/Emacs -Q \
  -L /path/to/EmacsanaganoYabo \
  -l sengoku.el \
  -f sengoku
#+end_src

ターミナル内で起動する場合は ~-nw~ を追加します。

#+begin_src sh
/Applications/Emacs.app/Contents/MacOS/Emacs -Q -nw \
  -L /path/to/EmacsanaganoYabo \
  -l sengoku.el \
  -f sengoku
#+end_src

* 起動

- ~M-x sengoku~ — 新規ゲームを開始し、32家から大名家を選択
- ~M-x sengoku-load~ — セーブデータを読み込んで再開

大名家と武将の選択時には、番号付きの候補一覧が自動表示されます。番号だけを入力して ~RET~ を押すか、候補をクリックして決定できます。

#+begin_example
大名家を選択 (1-32):

1. 南部家 — 南部晴政 (1国)
2. 伊達家 — 伊達晴宗 (1国)
3. 相馬家 — 相馬盛胤 (1国)
...
14. 織田家 — 織田信長 (1国)
...
32. 島津家 — 島津貴久 (1国)
#+end_example

進行中のゲームを新規開始またはロードで置き換える場合は、セーブするか、セーブせず置き換えるかを確認します。ゲームバッファを閉じる場合も同様です。

ミニバッファでの選択中に ~C-g~ を押した場合は、現在の選択だけを中止し、ゲームは終了しません。武将や対象の選択をキャンセルしても、領国や武将の行動権は消費しません。

* ゲームのルール

- 1ターンは1ヶ月です。
- 自領それぞれで1コマンドを実行した後、他の大名家が行動します。
- 月末には商業収入、兵糧消費、9月の収穫、台風、一揆、商人、外交などの処理が発生します。
- *全41ヶ国を制圧すれば天下統一（勝利）*です。
- *全領土を失えば滅亡（敗北）*です。
- 月初に所有していた領国だけが、その月の行動対象になります。
- 委任国は直轄国の後に、残った未行動武将を使って自動運営されます。

** 武将システム

武将は *戦才* と *政才* を持ち、1人につき月1回だけ行動できます。武将数が、その月に実行できる武将依存コマンドの上限になります。

- 開発・商業・施しは担当武将の政才で効果が変化
- 訓練は担当武将の戦才で効果が変化
- 出陣では大将を選び、大将の戦才が全部隊の戦闘力に影響
- 守城側は在城武将のうち最も戦才の高い武将が自動で指揮
- 外交と朝廷の使者は政才が成功率に影響
- ~B~ で自家の武将一覧を表示し、行動済みの武将には「済」を表示

武将選択時は、その月にまだ行動していない武将だけが番号付きで表示されます。

#+begin_example
開発を任せる武将 (1-8):

1. 織田信長 (政88 戦94)
2. 柴田勝家 (政55 戦88)
3. 木下藤吉郎 (政90 戦75)
...
#+end_example

政治系コマンドでは政才、軍事系コマンドでは戦才を先に表示します。

* 戦略画面の操作

専用の ~sengoku-mode~ は ~special-mode~ から派生しています。キーを1回押すごとにプレイヤーの行動を1つだけ処理し、AIと月末処理は次の入力待ちまで自動で進みます。ゲームバッファを隠してもセッションは継続します。

| キー | コマンド | 効果 |
|------+----------+------|
| ~1~ | 開発 | 武将と金200を使い、政才に応じて石高を上昇 |
| ~2~ | 商業 | 武将と金200を使い、政才に応じて商業を上昇 |
| ~3~ | 施し | 武将・金100・米100を使い、民忠を上昇 |
| ~4~ | 徴兵 | 武将・金・米を使って兵を増強 |
| ~5~ | 訓練 | 武将と金100を使い、戦才に応じて訓練度を上昇 |
| ~6~ | 鉄砲購入 | 金300で鉄砲を購入。武将は不要 |
| ~7~ | 出陣 | 大将を選び、隣接する敵領へ侵攻 |
| ~8~ | 輸送 | 隣接する自領へ金・米・兵を輸送 |
| ~9~ | 外交 | 同盟の申し入れ、同盟破棄、諸家の状況表示 |
| ~C~ | 朝廷 | 献金による官位獲得、または勅命和睦 |
| ~N~ | 南蛮交易 | 港のある国で鉄砲・大筒・珍品を購入 |
| ~T~ | 茶会 | 茶器を使って全領土の民忠と文化度を上昇 |
| ~B~ | 武将一覧 | 自家の武将と行動状況を表示 |
| ~A~ | 委任 | 現在の国を家臣に任せる |
| ~R~ | 委任解除 | 委任中の国を直轄に戻す |
| ~i~ | 国情報 | 任意の国の詳細を表示 |
| ~0~ / ~SPC~ | 待機 | 現在の国では何もしない |
| ~E~ | 残り全国待機 | この月の残りの直轄国をすべて待機 |
| ~S~ | セーブ | 現在のゲームを保存 |
| ~Q~ | 降参 | 確認後にゲームを終了 |
| ~RET~ / ~SPC~ | 再開 | 保留中の戦闘・申し出・全国委任月を再開 |

情報・武将・諸家の状況表示は、領国の行動を消費しません。領地が増えたら後方の国を ~A~ で委任し、前線だけを直轄すると快適に進行できます。

* 朝廷と官位

- ~C~ で使者を立てて金1000を献上すると、官位を授かる可能性があります。
- 官位は従五位下 → 従四位下 → 従三位 → 参議 → 権大納言 → 内大臣 → 関白の順です。
- 成功率は使者の政才と文化度で上昇します。
- 山城（京）を領有していると成功率が30%上昇します。
- 叙任されると全領土の民忠が8上昇し、外交成功率も上がります。
- 官位を持つ大名家は、金2000で任意の家へ勅命和睦を申し入れられます。

* 南蛮交易と大筒

南蛮港は次の5ヶ所です。

- 堺（摂津）
- 博多（筑前）
- 府内（豊後）
- 平戸（肥前）
- 坊津（薩摩）

港のある国では、鉄砲の大量購入、大筒の購入、南蛮の珍品の購入ができます。文化度が高いほど価格が安くなり、最大50%まで割引されます。

大筒は城門と城壁への攻撃に有効ですが、1門につき兵1500が必要です。出陣兵数が少ない場合は持ち出せません。

* 茶器と文化度

名物茶器は10点あります。

九十九髪茄子・平蜘蛛釜・初花肩衝・新田肩衝・楢柴肩衝・三日月茶壷・松島の壷・珠光小茄子・曜変天目・青磁千声

- 商人がときどき名物を売りに来ます。
- 初期所持は松永家、三好家、今川家です。
- 文化度は商業収入、鉄砲購入数、外交成功率に影響します。
- 茶器の入手と茶会で文化度が上昇します。
- 大名家を滅ぼすと、その家の茶器をすべて接収できます。

* 外交

- ~9~ の外交から、金500の贈物を添えて同盟を申し入れられます。
- 成功率は大名の魅力、文化度、茶器数、使者の政才に影響されます。
- 同盟中は互いに攻撃できません。
- 同盟破棄はいつでも可能ですが、文化度が3低下します。
- 他の大名家同士も同盟を結びます。
- 他家から同盟の申し出が来る場合があります。
- 大名家が滅亡すると、その家が結んでいた同盟はすべて消滅します。

* 合戦

** 自動戦闘

AI同士の合戦、委任国の合戦、プレイヤーが自動解決を選んだ合戦は自動処理されます。

- 最大8合
- 守備側は2割の防御補正
- 初期兵力の4分の1未満になると撤退
- 無防備な国は即時占領
- 鉄砲と大筒は兵力に応じて帰還・接収

** 籠城戦

プレイヤーが関わる合戦では、「采配を振るいますか？」の確認から戦術籠城戦を選択できます。

#+begin_example
■ 三河城 攻防戦   3日目/30日
攻手:織田軍 兵4000★  守手:松平軍 兵4200

  ・・・・・・・・・・・・
  ・・・森・・・・・・・・    攻１ 兵800 砲12←   守甲 兵840 砲2
  ・・・・・・壁壁壁壁壁・    攻２ 兵800 砲12    守乙 兵840 砲2
  ・・森・・２壁甲・・壁・    攻３ 兵800 砲12    守丙 兵840 砲2
  １・・・・・門・・本壁・    攻４ 兵800 砲12    守丁 兵840 砲2
  ・・・・森５壁・・丁壁・    攻５ 兵800 砲12    守戊 兵840 砲2
  ・・・・・３壁壁壁壁壁・

- 盤面は9行×12列です。
- 兵力は最大5部隊に分かれます。
- 1ターンは1日で、最大30日です。
- 攻め手は本丸を占拠するか、守備兵を全滅させれば勝利です。
- 守り手は30日間守り切れば勝利です。
- 森では被害が20%減少します。
- 城内の守備側は被害が30%減少します。
- 城門の耐久は120、城壁の耐久は200です。

| キー | コマンド |
|------+----------|
| ~h~ / ~j~ / ~k~ / ~l~ | 左 / 下 / 上 / 右へ1マス移動 |
| 矢印キー | 対応する方向へ1マス移動 |
| ~a~ | 隣接する部隊・門・壁を攻撃 |

* セーブデータ

既定の保存先は ~user-emacs-directory~ 配下の ~sengoku-save.json~ です。一般的な構成では次のいずれかになります。

- =~/.emacs.d/sengoku-save.json=
- =~/.config/emacs/sengoku-save.json=

保存先は次のコマンドで変更できます。

#+begin_example
M-x customize-option RET sengoku-save-file
#+end_example

セーブには年月、プレイヤー、領国、ログ、大名家状態、同盟をversion 5 JSON形式で保存します。月内の武将行動済み状態、途中の籠城戦、セッションの入力段階、画面状態は保存しません。

* 攻略のヒント

- 最初の1年は開発・商業・訓練を優先します。
- 攻める場合は相手の1.5〜2倍の兵と十分な鉄砲を用意します。
- 兵は毎月「兵数÷50」の米を消費します。
- 9月の収穫まで兵糧が足りるか確認します。
- 他家同士の戦いで消耗した国を狙うのが効果的です。
- 奪った直後の国は民忠が低いため、施しで一揆を防ぎます。
- 弱小大名でのプレイは高難度です。
- 領国が増えたら後方を委任し、前線へ武将と資源を集中します。

* セルフテスト

Emacs内から次のコマンドを実行できます。

- ~M-x sengoku-self-test~ — 静的データ、マップ整合性（隣接対称・グリッド衝突・名前解決）、全32家AIの36ヶ月進行、110桁マップと実際の戦略画面描画を検証し、専用プレビューバッファに描画結果を表示
- ~M-x sengoku-siege-test~ — 6回の自動籠城戦を検証

完全なERTスイートは次のように実行します。

#+begin_src sh
/Applications/Emacs.app/Contents/MacOS/Emacs --batch -Q \
  -L . -L test \
  -l test/sengoku-core-test.el \
  -l test/sengoku-combat-test.el \
  -l test/sengoku-engine-test.el \
  -l test/sengoku-ui-test.el \
  -f ert-run-tests-batch-and-exit
#+end_src

別の場所にあるEmacsを使う場合は、先頭の実行ファイルを置き換えてください。

* 開発者向け

Emacs Lisp実装は次のモジュールに分かれています。すべて ~lexical-binding: t~ を使用します。

- ~sengoku-data.el~ — 41ヶ国、32大名家、256武将、10茶器の固定データ
- ~sengoku-core.el~ — ゲーム状態、初期化、検索、同盟、茶器、征服処理
- ~sengoku-save.el~ — version 5 JSONセーブの読み書きと検証
- ~sengoku-combat.el~ — 自動戦闘と戦術籠城戦
- ~sengoku-engine.el~ — 戦略コマンド、AI、ターン、月末イベント、勝敗判定
- ~sengoku-ui.el~ — 専用モード、描画、補完、キーコマンド
- ~sengoku.el~ — 公開コマンドとパッケージライフサイクル

テストは次のファイルに分かれています。

- ~test/sengoku-core-test.el~
- ~test/sengoku-combat-test.el~
- ~test/sengoku-engine-test.el~
- ~test/sengoku-ui-test.el~

乱数を使うゲーム処理は ~sengoku-random~ に集約され、テストでは ~sengoku-random-function~ を差し替えて再現可能にしています。日本語レイアウトの検証には文字数ではなく表示幅を使用し、戦略マップの各行が110表示桁、各国セルが10表示桁であることをERTで確認します。
